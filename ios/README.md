# Вывеска — iOS IPA

GitHub Actions на `macos-14` собирает unsigned IPA (обёртка WKWebView + встроенный веб-редактор).

Файл артефакта: **Vyveska.ipa**.

Установка на iPhone/iPad без аккаунта Apple Developer:

1. [Sideloadly](https://sideloadly.io) или AltStore / SideStore
2. Свой Apple ID (бесплатный, сертификат на 7 дней)
3. Подключить устройство и поставить IPA

Для App Store / TestFlight нужны сертификат и профиль в секретах репозитория.
